Request a DNS change

Use this service to create an Azure DevOps pull request for a DNS record in the managed zone. The service does not write directly to Cloud DNS.

Before you start

Normal A, CNAME, and TXT records use the existing DNS zone. You only need nameservers when requesting an NS delegation for a subdomain.

Choose the DNS record type

How the request is processed

  1. The request is validated by this service.
  2. The service creates an Azure DevOps branch and pull request.
  3. Azure Pipelines validate the DNS manifest.
  4. After approval and merge, Argo CD and ExternalDNS apply the DNS change.

DNS record details

Enter the record values to include in the pull request.

.simardeep.xyz

Enter only the subdomain label. Do not include the parent zone.

Use one or more IPv4 addresses. Put each value on a new line.

Use 300 seconds for testing. Use a longer value for stable production records.

Requester information

Provide ownership metadata so reviewers know who is responsible for the DNS record.

If left blank, the service will generate a temporary project ID.

Use the Azure DevOps repository that owns the application or service.

Review and submit

The service will open a pull request. Nothing is applied to DNS until the pull request is approved and merged.

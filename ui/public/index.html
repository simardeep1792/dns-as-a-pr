How this works

            
This service opens an Azure DevOps pull request only. Azure Pipelines validate the manifest, then Argo CD and ExternalDNS apply it after merge.

            
UI -> Azure DevOps PR -> Azure Pipelines -> Merge -> Argo CD -> DNSEndpoint -> ExternalDNS -> Cloud DNS

            
Git is the source of truth. The UI does not write Cloud DNS directly.
